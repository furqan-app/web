١. حساب الوتيرة الثابتة (By Pace):
unitsPerDay = (period === "week") ? (amount / 7) : amount; estimatedDays = Math.ceil(totalUnits / unitsPerDay);
٢. حساب الموعد المستهدف (By Deadline):
days = Math.max(1, dayCountInclusive(today, endDate)); dailyPace = Math.ceil((totalUnits * K) / days);

⚠️ تنبيه معماري: هذا الحساب يُعرض للمستخدم فقط (Display-Only) ولا يُحفظ في قاعدة البيانات؛ السيرفر هو المصدر الوحيد لحساب وتحديث الجداول.
